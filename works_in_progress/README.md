# Works in Progress

This directory holds publication candidates that emerged from conversations but are not yet treated as finished articles.

See [INDEX.md](INDEX.md) for the work list and the relationship to the separate Human Image Project workspace.

Each work owns:

- `current.md` — its current, explicitly provisional formulation;
- `sessions.md` — the conversation records that substantiate its development.

The folders are intentionally independent: sharing a theme does not make the works one article.

Where a complete current draft already exists elsewhere, `current.md` is a link to that canonical file so the work does not silently fork into competing versions.
